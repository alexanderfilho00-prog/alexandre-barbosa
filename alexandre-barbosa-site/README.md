# Alexandre Ribeiro Barbosa

Apresentação profissional: Executivo de Finanças · Tesouraria Global · Governança.

Site estático em um único arquivo (`index.html`), sem etapa de build.

## Publicar no Vercel
1. Envie estes arquivos para um repositório no GitHub.
2. No Vercel: **Add New → Project**, escolha o repositório, deixe **Framework Preset: Other** e clique em **Deploy**.

Para atualizar, substitua o `index.html` no repositório; o Vercel republica automaticamente.
